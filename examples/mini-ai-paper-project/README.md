# Mini AI Paper Project Example

This example shows the expected artifacts for the AI-SCI-SKILLs workflow.
It is intentionally small and uses placeholder research content so the skill
suite can be tested without claiming real experimental novelty.

## Suggested Workflow

1. Use `ai-project-digest` on `materials/project_notes.md`.
2. Use `ai-experiment-analyzer` on `experiments/results.csv`.
3. Use `ai-literature-review` to replace `[CITATION NEEDED]` entries with verified papers.
4. Use `ai-paper-orchestrator` to update the project state.
5. Use `ai-sci-paper-writer` to draft from the files in `outputs/`.
