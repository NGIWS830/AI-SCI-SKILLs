# API Literature Search Guide

## Available APIs

| API | URL | Requires Key? | Rate Limit | Best For |
|-----|-----|--------------|------------|----------|
| Semantic Scholar | api.semanticscholar.org | No (API key for higher limits) | 100/5min (no key), 1000/5min (with key) | Broad AI/CS search with citation data |
| arXiv | export.arxiv.org | No | 1 request/3s (polite use) | Preprints, latest results |
| CrossRef | api.crossref.org | No | 50/s (polite use: 1/s) | DOI verification, metadata completeness |
| DBLP | dblp.org | No | No stated limit (use <1/s) | CS venue verification, author disambiguation |

## Script Usage

### Basic Search

```bash
python literature/scripts/search_literature.py "cross-modal retrieval with contrastive learning" \
    --sources s2,arxiv \
    --max 30 \
    --output lit_results.md
```

### Search from Query File

Create a `queries.txt` with one query per line, then:

```bash
python literature/scripts/search_literature.py --query-file queries.txt \
    --sources all \
    --format matrix \
    --output lit_matrix.md
```

### Citation Verification

```bash
# Verify a list of citations
python literature/scripts/verify_citations.py citations.txt \
    --sources crossref,dblp \
    --output verified.md

# Verify BibTeX entries
python literature/scripts/verify_citations.py --bibtex refs.bib \
    --verify-all \
    --output bib_verified.md
```

## Query Crafting Guide

### Effective Query Patterns

**Dataset-specific:**
```
"[dataset_name] benchmark semantic segmentation"
"evaluation on [dataset_name] [metric]"
```

**Method-family:**
```
"[method_family] [task]"
"end-to-end [task] transformer"
"contrastive learning for [task]"
```

**Gap-focused:**
```
"[task] fine-grained [aspect] limitation"
"small object detection scale variation"
"domain shift [task] robustness"
```

**Classic papers (use with seed maps):**
```
"foundational [task] benchmark survey"
"[seminal_paper_title_keyword] [task]"
```

### Query Expansion

The script automatically expands queries. You can disable with `--no-expand`. Expansion adds:
- Broad variant (first 2-3 terms)
- Method-focused variant (+ "deep learning" / "transformer")
- Recent variant (+ "2024 2025")

## Which Source to Use When

| Scenario | Primary Source | Secondary | Why |
|----------|---------------|-----------|-----|
| Finding SOTA baselines | Semantic Scholar | arXiv | S2 has citation data to identify influential recent papers |
| Classic/foundational papers | Seed maps (reference files) | S2 | Seed maps ensure you don't miss pre-2015 papers with lower citation velocity |
| Verifying metadata | CrossRef | DBLP | CrossRef has the most complete metadata |
| Finding latest preprints | arXiv | S2 | arXiv is the source of record for preprints |
| CS venue verification | DBLP | CrossRef | DBLP is curated for CS venues |
| Building BibTeX | CrossRef + DBLP | — | Combine for most complete entries |

## Interpreting API Results

### Semantic Scholar Fields
- **paperId**: Unique S2 identifier. Stable across queries.
- **citationCount**: Total citations. Use as a rough quality signal, not a definitive ranking — recent papers are penalized, survey papers are inflated.
- **externalIds**: DOI, ArXiv ID. Cross-reference with other sources. When both are present, the paper is well-indexed.
- **venue**: May be empty for preprints or very recent publications.
- **abstract**: Generated by S2's extraction, not the original abstract. For critical reading, go to the source paper.

### arXiv Fields
- **id**: The arXiv ID (e.g., `2301.12345`). Use to construct the URL: `https://arxiv.org/abs/{id}`.
- **published**: Original submission date. Updated versions have a different "updated" date.
- **category**: arXiv category (e.g., `cs.CV`, `cs.CL`). Useful for filtering.

### CrossRef Fields
- **DOI**: The definitive identifier. Always stable.
- **container-title**: Journal or conference name. May use abbreviated form.
- **published-print**: Print publication date. May differ from online date.
- **author**: Given name + family name. More structured than arXiv.

### DBLP Fields
- **venue**: Conference acronym (e.g., "CVPR", "NeurIPS") or journal name. Highly reliable for CS venues.
- **url**: DBLP page URL. Good for finding related papers by the same authors.

## Rate Limit Management

- The scripts include automatic retry with exponential backoff for 429 (rate limit) responses.
- Default delay: 0.5s between queries (search_literature.py), 0.3s between verifications (verify_citations.py).
- For large batch searches, consider running overnight or obtaining API keys.
- Semantic Scholar API key: register at https://api.semanticscholar.org/ and set `SEMANTIC_SCHOLAR_API_KEY` env var.
- If you hit arXiv rate limits, wait 5 minutes before retrying.
- CrossRef prefers you to identify your project: include a mailto link in the User-Agent (configured in script).

## Limitations

1. **Coverage gaps**: APIs index primarily English-language CS literature. Non-English or humanities-adjacent AI work (e.g., digital humanities, computational social science) may be under-indexed.
2. **Recency lag**: CrossRef and DBLP have a delay of weeks to months for new publications. arXiv is immediate for preprints but lacks peer-review metadata.
3. **Citation count inflation**: Review and survey papers accumulate citations faster than method papers. A high citation count doesn't mean "best method."
4. **No full-text search**: These APIs search titles, abstracts, and metadata only. They cannot search the full text of papers.
5. **Author disambiguation**: Multi-source deduplication by title is imperfect. Papers with very similar titles by different authors may be incorrectly merged or separated.
