# CV/NLP/AI Task Taxonomy

- Image classification
- Object detection
- Semantic segmentation
- Instance segmentation
- Medical image analysis
- Remote sensing image analysis
- Image restoration/enhancement
- Image generation
- Video understanding
- Pose estimation
- Few-shot / domain adaptation / continual learning

- Text classification
- Sequence labeling and NER
- Machine translation
- Question answering
- Summarization
- Information extraction
- Dialogue systems
- Retrieval-augmented generation
- Long-document understanding
- LLM evaluation and alignment

## Multimodal Learning

- Vision-language pretraining
- Image-text retrieval
- Visual question answering
- Document understanding
- Video-language modeling
- Medical VQA
- Multimodal instruction tuning

- CNN, RNN, Transformer, ViT
- Attention and cross-attention
- Contrastive learning
- Diffusion models
- Graph neural networks
- Prompt learning and adapters
- LoRA and parameter-efficient tuning
- Retrieval-augmented generation
- Multiscale feature fusion
- Domain adaptation and generalization
