## 5. Commonly Confused Pairs — 高频混淆词对

These are the most common translation errors in AI papers. Check these CAREFULLY.

| 中文 | ❌ Wrong Translation | ✅ Correct Translation | Why It's Confused |
|------|---------------------|----------------------|-------------------|
| 精度 | precision | **performance / accuracy / precision** (context-dependent!) | 精度 can mean "precision" (查准率), "accuracy" (准确率), or general "performance". Must disambiguate by context. |
| 准确率 | precision / performance | **accuracy** | 准确率 specifically means accuracy (% correct). |
| 精确率 | accuracy | **precision** | 精确率 specifically means precision (TP/(TP+FP)). |
| 模型 | mode / mold | **model** | Spelling error common among non-native writers. |
| 模块 | mode / mold | **module** | Same as above. |
| 架构 | structure / construction | **architecture** | 架构 implies design; structure implies organization. |
| 框架 | architecture / frame | **framework** | Framework = software system; architecture = network design. |
| 方案 | plan / project / proposal | **approach / method / solution** | 方案 is a catch-all term. In AI papers, "approach" or "method" is usually correct. Avoid "scheme" (can imply deception in English). |
| 机制 | system / machine | **mechanism** | 机制 = principled process. "Mechanism" is correct for describing how something works. |
| 策略 | policy / plan | **strategy / approach** | In ML, "policy" specifically means a decision function in RL. For general use, use "strategy". |
| 性能 | property / capability | **performance** | 性能 = performance (quantifiable). Not "property" or "capability". |
| 效果 | result / outcome | **effectiveness / performance** | 效果 can be "effect" (causal) or "performance" (evaluative). |
| 贡献 | contribution / donation | **contribution** | 贡献 = contribution (学术). "Donation" is incorrect in academic context. |
| 效率 | efficiency / effectiveness | **efficiency** (if about speed/cost) or **effectiveness** (if about accuracy) | These are different concepts! |
| 实验 | experiment / test | **experiment** | 实验 = experiment. "Test" is too narrow. |

## Usage Notes

1. **Before translating**: Scan for terms in this corpus. If found, use the ✅ translation exactly.
2. **If not found**: Check `ai-terminology-glossary.md` for the base mapping. Search the web for the term used in published papers.
3. **When a Chinese term has multiple English equivalents**: Disambiguate by context. For example, 精度 could be "accuracy" (if reporting %correct), "precision" (if reporting TP/(TP+FP)), or "performance" (if used generically).
4. **Never guess**: If uncertain, mark as `[TRANSLATION_UNCERTAIN: <Chinese term>]` and flag for review.
5. **Consistency is key**: Once you choose a translation for a term, use it throughout the entire manuscript.
