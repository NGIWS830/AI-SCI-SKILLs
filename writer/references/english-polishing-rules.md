# English Polishing Rules

## Default style

Use conservative SCI journal style: clear, precise, formal, and not overdecorated.

## Modes

- Conservative polishing: grammar, clarity, flow.
- Academic rewriting: restructure sentences and paragraphs.
- IEEE style: concise and technical.
- AI conference style: clear problem formulation and empirical rigor.
- Nature-leaning style: stronger narrative, but no unsupported significance claims.

## Never

- Strengthen claims without evidence.
- Add unsupported “state-of-the-art”, “novel”, “significant”, “first”, or “comprehensive”.
- Change metric values or dataset names.
- Remove caveats.
