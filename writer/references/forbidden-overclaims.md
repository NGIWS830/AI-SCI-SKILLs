# Forbidden Overclaims

Do not write these unless explicitly supported:

- state-of-the-art
- first / 최초 / 首次
- solves the problem
- proves
- universally applicable
- significantly improves
- robust across all scenarios
- comprehensive comparison
- negligible cost

Use safer alternatives:

- achieves competitive performance
- improves over selected baselines
- alleviates
- suggests
- demonstrates potential
- improves in the evaluated settings
