# Reproducibility Checklist

Check whether the experiment section includes:

- Dataset names and splits
- Preprocessing details
- Baseline implementation source
- Metric definitions
- Training epochs, batch size, optimizer, learning rate
- Hardware information
- Number of runs and seeds if available
- Variance or standard deviation if available
- Code availability statement if relevant
- Hyperparameter selection method

Mark missing items as `AUTHOR_INPUT_NEEDED`.
