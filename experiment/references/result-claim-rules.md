# Result Claim Rules

## Evidence strength

- Strong: multiple datasets or metrics support the same claim.
- Moderate: one main dataset and one or more metrics support the claim.
- Weak: one metric or one setting supports the claim.
- Unsupported: no direct result supports the claim.

## Wording

- Strong: “consistently improves...” only if improvements are consistent.
- Moderate: “achieves better performance on...”
- Weak: “suggests potential benefits...”
- Unsupported: do not claim; mark as unsupported.

## Forbidden upgrades

Do not convert:

- “improves on one dataset” -> “generalizes well”
- “slightly improves” -> “significantly improves”
- “competitive” -> “state-of-the-art”
- “reduces latency in one setting” -> “is efficient” without caveat
